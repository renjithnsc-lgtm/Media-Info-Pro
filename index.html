Export Database

Download your complete database of programmes as a single `.json` file for backup or sharing.

This download contains all programme details, executive names, phone numbers, and team listings. You can import this file on any device running Media-Info Pro 1.0.

Import Database

Load records from a previously exported `.json` backup file.

Caution: Importing a file can overwrite or merge with current records. Please make sure the JSON format matches a valid Media-Info Pro 1.0 backup.
